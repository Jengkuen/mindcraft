# Workspaces

Store project execution here: plans, working materials, evidence, artifacts and resumable handoffs. Link to an existing workspace elsewhere when that is more useful than moving it.

Before an execution project becomes active:

1. Create a project workspace README linking to its [Netherite](../netherite/README.md) project and each active workstream's control.
2. Define each workstream's objective, approval boundary, current state, next checkpoint and exit condition in its control.
3. Obtain the user's approval of the workspace and initial workstreams. An explicit instruction that already defines and approves them is sufficient.

Keep detailed tasks and evidence in the workspace; expose only current management tasks in Netherite. Completing tasks does not close a workstream or project without deliberate review.
